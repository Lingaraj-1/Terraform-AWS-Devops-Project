# 🚀 Terraform AWS DevOps Project

## 📌 Overview

This project provisions AWS infrastructure using Terraform with a modular approach.

## 🏗️ Architecture

* VPC
* Subnet
* Internet Gateway
* Route Table
* Security Group
* EC2 Instance

## ⚙️ Tools & Technologies

* Terraform
* AWS (EC2, VPC)
* Git & GitHub

## 📂 Project Structure

modules/
├── vpc
├── subnet
├── igw
├── route-table
├── security-group
└── ec2

## 🚀 What this project does

* Creates custom VPC
* Launches EC2 instance inside subnet
* Configures networking (IGW + Route Table)
* Applies security rules

## ▶️ How to Run


terraform init
terraform plan
terraform apply


## 📌 Key Learning

* Modular Terraform design
* Infrastructure as Code (IaC)
* AWS networking basics
